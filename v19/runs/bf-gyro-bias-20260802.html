Fault injection · single stuck bit, gyro X · scored run

A gyro fault the firmware had to fly through.

This is a sensor fault injection test. Mid-hover, the bench forces bit 11 high in every gyro X sample it serves the firmware, the way a stuck line or a failed converter bit would. The word is otherwise untouched. Unmodified Betaflight cannot tell the sensor is lying, so it corrects against a rotation that is not there.

The run

red dashed line fault injected at t+8.0 s
gyro X rate served to the firmware · ±2600 LSB · bit 11 = 2048
roll mix (M3+M4) − (M1+M2), decoded from the DShot outputs · ±4000
collective sum of the four motor outputs · 0 to 6000 · 13 s of run

Hover is flat: gyro X at 0, roll mix at 4. The bit sticks at t+8.0 and the mix answers within 80 ms, reaching −3746 as the firmware corrects against the false rotation. The served rate settles at exactly +2048, the weight of the stuck bit. A build that mishandled the gyro would have left the mix flat.
