Fault injection · single stuck bit, gyro X · scored run

A gyro fault the firmware had to fly through.

This is a sensor fault injection test. Eight seconds into a hover, the bench forces bit 11 high in every gyro X sample it serves the firmware, the way a stuck line or a failed converter bit does: once it sticks, it stays stuck. The word is otherwise untouched. Unmodified Betaflight cannot tell the sensor is lying.

The run

red dashed line fault injected at t+8.0 s
gyro X rate served to the firmware · ±2600 LSB · bit 11 = 2048
roll mix (M3+M4) − (M1+M2), decoded from the DShot outputs · ±4000
collective sum of the four motor outputs · 0 to 6000 · 45 s of run

Hover is flat: gyro X at 0, roll mix at 4. The bit sticks at t+8.0 and the mix answers within 74 ms, reaching −3746. Then it keeps going. For the 37 seconds that follow, the served rate averages +2035 and the firmware never stops correcting for a rotation that is not happening: it does not detect the fault, does not flag it, and is still armed and flying when the capture ends.
